# 黑洞桌宠

一款运行在 Windows 桌面上的动态黑洞宠物。

开发者：**凌晨曦**

## 下载

请从本仓库右侧的 **Releases** 页面下载最新版本。

下载 `黑洞桌宠-v1.4-win-x64.zip`，完整解压后双击 `黑洞桌宠.exe` 即可运行。

## 主要功能

- GPU 实时渲染的动态黑洞与吸积盘
- 三种可切换观察形态
- 局部螺旋空间扭曲
- 可调节的鼠标引力
- 文件拖入黑洞后移动到 Windows 回收站
- 吞入文件后体型逐渐增大
- 清空回收站或重启后恢复基础体型
- 系统托盘设置与退出

## 基本操作

- 拖动黑洞：移动桌宠位置
- 双击黑洞：切换观察形态
- 拖入普通文件：播放吸入动画并移动到回收站
- 右键托盘图标：打开设置、居中或退出

## 系统要求

- Windows 10 / 11 x64
- 支持 WebGL2 的显卡与驱动
